# Messy Python Code Improvement

This project demonstrates the improvement of a poorly formatted Python program into a cleaner and more structured version.

## Files Included

### messy_[code.py](http://code.py)

Contains the original messy Python program with poor formatting and a simple structure.

### improved_[code.py](http://code.py)

Contains the improved version with:

- Functions for better organization
- Meaningful variable handling
- Consistent indentation
- Cleaner output
- Better code readability

## Technologies Used

- Python
- Functions
- Conditional Statements
- User Input

## Objective

The objective of this project is to demonstrate how messy Python code can be improved using AI-assisted coding and better programming practices.
